# Cookeville Council Watch

An independent, source-linked record of formal Cookeville City Council action items and the public comment made during each item's official public-comment or public-hearing block.

## Scope

- The tracker records formal action items, including resolutions, ordinances, contracts, grants, and consent-agenda actions.
- An item with no speaker is shown as **No public comment recorded**. That does not mean public support.
- A speaker is counted toward an item's sentiment only when the official meeting record or video places the statement in that item's public-comment/public-hearing block.
- General remarks during **Citizens Request for Hearing** or another non-item-specific segment are preserved in meeting notes when useful, but are never assigned to a vote.
- When the evidence does not establish a speaker count or a clear for/against position, the tracker says so. It does not infer one.

## Data and evidence

- Public data: [`docs/data/actions.json`](docs/data/actions.json)
- File checksums and known source issues: [`evidence/manifest.json`](evidence/manifest.json)

## Publish with GitHub Pages

This repository uses the GitHub Actions workflow in `.github/workflows/deploy-pages.yml`.

The site is intentionally static: no account, database, tracking, or editing interface is required. Every published data change is visible in Git history.
