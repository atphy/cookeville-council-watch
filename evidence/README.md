# Evidence archive

This directory preserves the meeting materials reviewed for Cookeville Council Watch.

- `official-minutes/` contains official minutes used for formal outcomes and member votes.
- `agendas/` contains official agendas.
- `transcripts/` contains supplied transcripts used as supplemental evidence for item-specific public-comment counts.

The tracker records comments only from the official public-comment or public-hearing block for that action. A transcript alone does not replace official minutes for a formal vote outcome. See [manifest.json](manifest.json) for file checksums and source notes.
